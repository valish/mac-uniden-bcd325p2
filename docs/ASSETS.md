## README illustration

File: [images/scanner-mac-illustration.jpg](images/scanner-mac-illustration.jpg).

Created on November 3, 2026 using the built-in OpenAI image-generation tool, from text only. The generated PNG was converted to JPEG at quality 85 for repository size; the composition was not retouched. No third-party photograph, logo or screenshot was used as an input. The generic scanner and laptop are illustrative, not an accurate BCD325P2 product drawing or wiring reference.

## Interface review

The refinement used the [Unslop UI skill](https://github.com/iamneilroberts/claude-skills/blob/main/skills/unslop-ui/SKILL.md), skill-file Git blob `2da11246f01c48ddbe85cd40f9aa266ce852eb91`, as a design review aid. The skill itself is not bundled.

The three main changes were compact channel/scan rows, literal task instructions with named review warnings, and local typography with restrained instrument-inspired colors. The heuristic scanner reported zero findings both before and after; that result is not a visual or accessibility certification. Browser checks and manual desktop, narrow-screen and print inspection provide the relevant evidence.
