Scanner reference

              
Programming success confirms memory. Listening confirms reception.

            

          

          

            

              
Start scanning

              

                After “Upload verified,” press Scan/Srch. Set volume and squelch. A
                quiet channel may simply have no traffic.
              

              

                Use the actual quick keys printed after upload. Press a one-digit key during
                scanning to toggle a system. For two digits, press ./no, then the
                two digits.
              

            

            

              
Keep continuous signals separate

              

                NOAA weather and broadcast FM transmit continuously. Enable those systems for
                deliberate listening, then disable them to return to ordinary incident scanning.
              

              
This programmer does not configure SAME weather-alert standby.

            

            

              
Understand receive limits

              

                P25 Phase I and II use P25 Standard systems with sites and talkgroups. Encrypted
                audio cannot be decoded. Terrain, antenna placement and simulcast distortion affect
                reception.
              

              

                DMR, NXDN, EDACS, LTR and Motorola Type II programming are outside this version’s
                scope.
              

            

            

              
If a session stops

              

                Keep the receipt. Reconnect and load the same plan. The programmer checks matching
                saved records before resuming. A timeout never triggers an automatic retry of a
                memory allocation.
              

              

                If Remote Mode remains on screen after a connection failure, power the scanner off
                and on before reconnecting.
